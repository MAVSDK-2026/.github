# .github
MAVSDK — набор библиотек и API для программного управления беспилотными аппаратами через MAVLink. Используется для разработки приложений под PX4 и совместимые системы, управления полётом и миссиями, получения телеметрии, работы с параметрами, камерой и другими функциями UAV из C++, Python и других языков.
