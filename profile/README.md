## Обзор проекта

**MAVSDK** — открытый набор библиотек и API для создания приложений, взаимодействующих с беспилотными аппаратами через протокол **MAVLink**. Проект предоставляет разработчику высокоуровневый программный интерфейс, позволяя управлять UAV без необходимости самостоятельно реализовывать обработку большого количества низкоуровневых MAVLink-сообщений.

MAVSDK широко применяется вместе с **PX4 Autopilot** и подходит для разработки наземных приложений, companion computer-систем, автономных решений, инструментов мониторинга и собственного программного обеспечения для управления беспилотными аппаратами.

Через API приложение может получать телеметрию, отправлять команды аппарату, работать с миссиями и параметрами, а также использовать дополнительные возможности, предоставляемые плагинами MAVSDK. Это делает платформу удобной как для небольших экспериментальных проектов, так и для более сложных программных комплексов вокруг UAV.

## Основные возможности

| Компонент | Назначение |
|---|---|
| **Action** | Основные команды управления аппаратом |
| **Telemetry** | Получение состояния и телеметрических данных |
| **Mission** | Создание, загрузка и управление миссиями |
| **Offboard** | Программное управление движением аппарата |
| **Parameters** | Чтение и изменение поддерживаемых параметров |
| **Camera** | Работа с поддерживаемыми функциями камеры |
| **Geofence** | Программная работа с геозонами |
| **MAVLink** | Связь с автопилотом через экосистему MAVLink |
| **PX4** | Основная платформа для интеграции и разработки |
| **SITL** | Тестирование приложений с программной симуляцией |
| **UDP / TCP / Serial** | Различные способы подключения к MAVLink-системам |

Вместо непосредственной отправки отдельных MAVLink-команд разработчик может использовать более понятные функции SDK. Например, приложение может обнаружить подключённый аппарат, подписаться на поток телеметрии и выполнять поддерживаемые действия через единый программный интерфейс.

## API, PX4 и разработка приложений

**MAVSDK** особенно полезен при создании собственного программного обеспечения поверх PX4. Это может быть приложение управления, автоматизированная система выполнения заданий, программа мониторинга, companion computer или сервис, взаимодействующий с одним или несколькими беспилотными аппаратами.

Основная реализация **MAVSDK C++** предоставляет API и набор специализированных плагинов. Экосистема проекта также позволяет использовать MAVSDK из других языков программирования, включая Python, в зависимости от выбранной реализации и версии SDK.

Связь с аппаратом обычно выполняется через MAVLink-соединение. В зависимости от конфигурации это может быть UDP, TCP или последовательный интерфейс, соединяющий приложение с реальным автопилотом либо программной симуляцией.

## MAVSDK и SITL

| Компонент | Применение |
|---|---|
| **PX4 Autopilot** | Автопилот для интеграции с MAVSDK |
| **MAVLink** | Протокол обмена сообщениями |
| **MAVSDK C++** | Основная библиотека для разработки |
| **MAVSDK-Python** | Использование API из Python |
| **SITL** | Тестирование без физического UAV |
| **Simulation** | Разработка и проверка логики управления |
| **Companion Computer** | Запуск пользовательского ПО рядом с автопилотом |
| **Ground Application** | Создание собственных наземных приложений |

Использование **PX4 SITL** позволяет разрабатывать и тестировать приложение MAVSDK без подключения реального аппарата. Автопилот запускается в программной среде, после чего приложение подключается к нему практически так же, как к физической системе через MAVLink.

Такой рабочий процесс особенно удобен для проверки логики миссий, телеметрии и программного управления перед испытаниями на реальном оборудовании.

## Пример подключения

Принцип работы приложения на MAVSDK обычно состоит из нескольких этапов: необходимо создать экземпляр SDK, добавить MAVLink-соединение, дождаться обнаружения системы и после этого использовать необходимые API или плагины.

Для реального проекта параметры соединения зависят от автопилота, сети и выбранной среды выполнения. При использовании PX4 SITL сетевое подключение обычно настраивается автоматически или задаётся в соответствии с конфигурацией симуляции.

Перед выполнением команд на физическом UAV рекомендуется сначала проверить приложение в SITL и убедиться, что логика управления корректно обрабатывает потерю соединения, ошибки выполнения команд и другие исключительные ситуации.

## Быстрый старт

1. Установите подходящую версию **MAVSDK**.
2. Подготовьте PX4 SITL или совместимый реальный автопилот.
3. Создайте проект на поддерживаемом языке программирования.
4. Добавьте MAVSDK в зависимости проекта.
5. Настройте MAVLink-соединение с системой.
6. Дождитесь обнаружения подключённого аппарата.
7. Подключите необходимые API для Telemetry, Action или Mission.
8. Проверьте работу приложения в симуляции.
9. Добавьте обработку ошибок и потери соединения.
10. Только после тестирования переходите к работе с реальным UAV.
